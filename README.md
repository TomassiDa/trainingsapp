# Trainingsapp

Persoonlijke trainingsapp voor thuis: drie trainingsdagen met dumbbells, bankje en workout station.

- Draait als web-app: open de link in Safari, kies Deel > Zet op beginscherm.
- Het logboek staat lokaal op de telefoon. Maak via "Back-up en instellingen" af en toe een back-up.
- Werkt offline dankzij de service worker (`sw.js`). Verhoog `VERSION` in `sw.js` bij elke update.
- Schema aanpassen: `data.js`.
- Plaatjes: [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) (public domain).
